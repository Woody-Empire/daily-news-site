DeepSeek

  • DeepSeek 筹划首次对外融资，目标估值超 100 亿美元
    据 The Information 报道，DeepSeek 正筹划成立以来首次对外融资，计划筹集至少 3 亿美元，目标估值超 100 亿美元。此举标志着其从依赖母公司幻方量化的"自我供血"模式转向引入外部资本。资金将主要用于扩大算力建设及推进因硬件适配等原因多次推迟的下一代旗舰模型 DeepSeek V4 的研发。报道指出，融资背后反映出研发成本攀升与核心研发人员流失的双重压力。

OpenAI

  • OpenAI 传向 Cerebras 采购超 200 亿美元算力
    据路透社援引 The Information 报道，OpenAI 同意未来三年向 AI 芯片公司 Cerebras 支付超 200 亿美元使用其芯片算力，并将提供约 10 亿美元资助数据中心建设。该协议可能使 OpenAI 获得 Cerebras 少数股权认股权证，若总支出达 300 亿美元，持股比例或升至约 10%。此前双方已有超 100 亿美元算力协议，新承诺规模约为前次两倍。双方均未置评。

🤖 模型发布

xAI

  • Grok 4.3 测试版上线，启用云计算机模式
    xAI 面向部分用户开启 Grok 4.3 (beta) 的 Early Access 测试。与前代采用 16 Agent 架构的 Grok 4.20 不同，该版本转型为云 Computer 模式，原生配备 shell 与持久化文件层。测试表明其支持从视频中提取音频、分析视频片段提取核心论点并自动生成结构化 PowerPoint 幻灯片，还能创建 PDF、Sheets、Docs 等多种格式文件。

QuiverAI — 专注 SVG 矢量图形 AI 生成的初创公司

  • 发布 Arrow 1.1 SVG 生成模型
    QuiverAI 发布最新 SVG 生成模型 Arrow 1.1 及高精度版 Arrow 1.1 Max。该系列通过代码直接生成矢量图形，增加基础几何图形使用比例、减少复杂路径依赖，输出更易编辑和扩展的结构化 SVG。生成和矢量化单价分别降至 $0.20 和 $0.15。Arrow 1.1 Max 针对技术图表等高精度场景，色彩还原与形状对齐更稳定，但运行时间与成本相应增加。模型已在官方平台开放公测。

Anthropic

  • 推出 Claude Design 视觉创作工具
    Anthropic Labs 推出实验性产品 Claude Design，由 Claude Opus 4.7 模型驱动，以研究预览版形式向 Claude Pro、Max、Team 和 Enterprise 订阅用户逐步开放。用户通过对话即可创建交互原型、幻灯片、单页文档等视觉设计作品，支持通过对话、行内评论、直接编辑或自定义滑块进行微调。产品能读取团队代码库和设计文件自动构建专属设计系统，确保品牌视觉一致性。输入支持网页捕获和文档导入（DOCX/PPTX/XLSX），输出可导出为 Canva 项目、PDF、PPTX、独立 HTML 文件，或打包交接给 Claude Code 进行代码开发。

Cloudflare

  • Email Service 公测，支持 AI Agent 集成
    Cloudflare 宣布专为 AI Agent 打造的双向邮件通信基础设施 Email Service 正式公测。结合免费 Email Routing 与新公测的 Email Sending，开发者可实现接收、处理并异步回复邮件的完整闭环，系统自动配置 SPF/DKIM/DMARC 确保高送达率。深度集成 Agents SDK 的 onEmail hook，利用 Durable Objects 实现跨邮件状态持久化，支持基于地址的智能路由及 HMAC-SHA256 安全回复。同时开源了具备人机协作功能的参考应用 Agentic Inbox，兼容 Claude Code 等外部 Agent 快速接入。功能包含在 Workers Paid plan 中。

Opera

  • 推出 Browser Connector，支持外部 AI 读取标签页
    Opera 为 Opera One 和 Opera GX 浏览器推出免费功能 Browser Connector，基于 MCP 标准，允许用户将 ChatGPT、Claude 等外部 AI 直接接入浏览器实时会话。AI 能够实时读取打开的标签页及页面内容，通过截图分析图像与图表，免去人工复制粘贴传递信息的繁琐步骤。目前已在 Early Bird 测试环境上线，用户需在设置中开启 Early Bird 模式并按指引完成授权连接。
