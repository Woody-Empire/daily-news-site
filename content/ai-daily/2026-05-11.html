OpenAI

  • Codex 周安装量达 8610 万，12 倍于 Claude Code
    据 a16z 引用 TickerTrends 数据，截至 5 月 3 日当周，OpenAI Codex 的 npm 周安装量达 8610 万，较此前约 1000 万急剧攀升，仅 5 月 2 日一天就新增 4600 万。同期 Anthropic Claude Code 周安装量为 720 万。媒体分析认为用户迁移主要由 Claude Code 遭遇的"智能降级"和混乱配额策略引发，OpenAI 则通过桌面应用、多 Agent 并行与超过 90 个插件的生态加速追赶。

  • OpenAI 终止开发者自助微调通道
    OpenAI 通过官方邮件宣布全面关停面向开发者的自助微调 API。即日起新用户无法创建微调任务，现有用户可使用至 2027 年 1 月 6 日，已部署的微调模型推理服务与底层基座模型生命周期绑定。OpenAI 给出的理由是新一代基座模型在指令遵循方面已极为强大，Prompt 配合 RAG 足以覆盖绝大多数场景。

Bun — 高性能 JavaScript/TypeScript 运行时

  • 创始人透露正在将 Bun 从 Zig 重写为 Rust
    Bun 创始人 Jarred Sumner 透露已开始将 Bun 运行时从 Zig 重写为 Rust，涉及约 96 万行代码迁移。重写版本已能在 Linux x64 glibc 上通过 99.8% 的现有测试套件。此举主要出于对内存泄漏和稳定性问题的长期担忧，希望利用 Rust 编译器强制生命周期管理来提升系统稳定性。Sumner 强调合并前必须确保性能、内存和稳定性均显著优于现有 Zig 实现。

AI API 灰色市场

  • 调查曝光"中转站"利用被盗凭证和模型替换盈利并出售用户数据
