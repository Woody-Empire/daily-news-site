Google

  • 推出 Android 开发工具集，优化 Agent 工作流
    Google 发布全新 Android 开发工具集，包含 Android CLI、Android skills 和 Android Knowledge Base 三大组件，支持 Gemini in Android Studio、Gemini CLI、Antigravity 及 Claude Code、Codex 等第三方 Agent。官方内部实验显示，通过 Android CLI 引导 Agent 进行环境配置和项目创建，可将 LLM Token 使用量降低 70% 以上，任务完成速度提升达 3 倍。Android Knowledge Base 提供来自 Android、Firebase 和 Kotlin 官方文档的实时权威参考。

browser-use — 开源浏览器自动化框架，让 AI Agent 控制浏览器执行任务

  • 推出 Browser Harness 开源工具
    browser-use 团队推出 Browser Harness，基于 CDP 通过单一 websocket 连接 Chrome，可在任务执行中动态编辑并补充缺失代码，已支持接入 Claude Code 和 Codex。底层约 592 行 Python 代码。配套提供免费远程浏览器服务，免费层支持 3 个并发浏览器，无需绑定信用卡，用户可自行获取 API 密钥或让 Agent 自动注册。

🇨🇳 中国公司动态

Cherry Studio — 开源跨平台 AI 桌面客户端，支持多模型接入

  • 被曝无视设置仍上传遥测数据
    Cherry Studio 被曝在用户关闭数据收集开关后，仍向 analytics.cherry-ai.com 发送遥测数据。启动和更新检查时触发的事件绕过了 enableDataCollection 设置，导致匿名 UUIDv7 Client-Id、版本号和操作系统等信息被强制上传。早期版本迁移代码还被发现静默将数据收集选项设为开启。目前已有用户提交修复 PR，社区普遍呼吁官方对开关失效问题作出正面回应。
