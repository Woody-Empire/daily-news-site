  • 千问发布新一代旗舰 Qwen3.7-Max
    千问正式发布面向 Agent 时代的旗舰模型 Qwen3.7-Max，主打编程、办公自动化与长周期自主执行能力。在 35 小时、1158 次工具调用的自主 kernel 优化实验中，实现参考实现 10.0 倍的几何平均加速。模型采用任务-运行框架-验证器正交解耦训练架构，原生适配 Claude Code、OpenClaw、Qwen Code 等主流智能体框架，支持 MCP 集成与多智能体协作。API 即将通过阿里云百炼上线。
    🔗 来源

  • 千问发布实时同传模型 Qwen3.5-LiveTranslate
    千问发布实时同传翻译大模型 Qwen3.5-LiveTranslate-Flash，基于 Qwen3.5-Omni Thinker-Talker 架构，支持 60 种语言音频输入、29 种语言语音输出，端到端字均延迟降至 2.8 秒，支持实时音色克隆及最高 1000 个词条的动态热词配置。在 FLEURS 等基准测试中翻译准确率优于前代，Demo 已开放体验。

  • Cohere 发布开源模型 Command A+
    Cohere 发布基于 Apache 2.0 许可的开源大模型 Command A+，采用 218B 总参数、25B 激活参数的 Sparse MoE 架构，支持 128K 上下文、64K 输出、图像输入及 48 种语言，专为 Agentic 任务优化。提供 BF16、FP8 和 W4A4 三种量化版本，W4A4 版本最低仅需单块 B200 或两块 H100 即可运行，权重已在 Hugging Face 发布。

NVIDIA

  • NVIDIA 推出 SANA-WM 分钟级视频生成模型
    NVIDIA 开源世界模型 SANA-WM（26 亿参数），支持单张图像+文本+6 自由度摄像机轨迹输入，生成 720p 分辨率 60 秒高保真视频。采用混合线性注意力与双分支摄像机控制架构，单块 H100 即可完成推理；经蒸馏与 NVFP4 量化后，单块 RTX 5090 上仅需 34 秒完成 60 秒视频去噪。代码与检查点已在 Hugging Face 开源。
