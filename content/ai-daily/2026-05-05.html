Vercel

  • Vercel 开源 deepsec：基于 AI Agent 的代码安全扫描框架
    Vercel 开源了基于 coding Agent 的安全扫描框架 deepsec，采用 CLI 设计支持本地运行。工作流涵盖静态分析、Agent 调查、二次验证、元数据丰富与导出五大阶段，设计了误报重验证环节以降低 10%–20% 的假阳性率。针对大型仓库支持 Vercel Sandboxes 远程并行扩展，开发者运行 npx deepsec init 即可上手。
